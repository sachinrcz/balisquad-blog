## How to Copy an Event on BaliSquad

Running the same dinner, game night, or cowork session again? Don't rebuild the listing from scratch. Use **Copy Event**.

It creates a new draft from your existing event so you can change the date (and anything else) before you publish.

---

### Steps

1. Open the event you want to reuse (you need to be a host or manager on it).
2. Tap **Manage Event**.
3. Open the **More** tab.
4. Tap **Copy Event** (the label is Copy Event, not Duplicate).
5. You'll land in the editor for the **new draft**. Update the start time, description, photos, or ticket tiers as needed.
6. Hit **Publish Event** when it's ready.

Routes under the hood: manage lives at `/event/[slug]/manage` (More tab); the new draft opens in edit.

---

### Tips

- Double-check the new date and area before you publish
- Refresh the cover photo if the last one was tied to a past night
- If tickets or custom questions should change for this round, edit those on the draft before publishing
