## How to Add Ticket Tiers on BaliSquad

Want a cover charge, early-bird price, or a limited number of spots? Use **Ticket tiers** on your event. You can add more than one tier. Payment is collected offline (BaliSquad does not process the money for you).

If you just need a free open RSVP, skip tickets. Most social meetups do.

---

### On a new event

1. Open [Add Event](https://balisquad.com/event/add) and fill the basics as usual.
2. Scroll to **Ticket tiers** (on mobile: Basics → Details → Settings → Finish, then Ticket tiers).
3. Tap **Add tier**.
4. Fill in:
   - **Name** (Early bird, Door, Member, and so on)
   - **Price (IDR)**
   - **Quantity**
   - **Description** (what's included)
   - Optional **Sales window** if sales should open or close at a set time
5. Add more tiers if you need them, then **Publish Event** (or save as draft).

---

### On an event you already published

1. Open your event page.
2. Go to **Manage Event** → **Overview** → **Edit Event**.
3. Find the **Ticket tiers** section → **Add tier** (or edit an existing one).
4. Fill Name / Price (IDR) / Quantity / Description / optional Sales window.
5. Hit **Update Event**.

**Heads-up:** Manage → **Tickets** is for stats and scanning, not for creating tiers. If that screen looks empty, add tiers by editing the event.

---

### Tips

- Keep tier names short and obvious
- Put how people pay (cash at the door, transfer, and so on) in the event description
- Use quantity when the room or court has a hard cap
